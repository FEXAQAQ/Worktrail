# Worktrail

> **寫程式的同時，日誌已經寫好了。**

![Worktrail 示範：今日任務、任務面板、日誌熱度圖、小交流、週報與筆記本風格](docs/images/demo.gif)

<sub>畫面為示範用的虛構資料。</sub>

Worktrail 是 Claude Code 的工作日誌系統。你照常在 Claude Code 裡開發，它在背後記下每個任務花了多少時間、處理哪張 Jira 單、做了哪些 commit，並由 Claude 整理成條列進度。到了週五，週報按一個鍵就出來；年底寫績效，也有整年的紀錄可以引用。

不用再回想「這週到底做了什麼」，也不用在下班前補寫日誌。

---

## 關於這套工具

每個工程師都有過這種時刻：週會前打開空白的週報，努力回想五天前修的是哪個 bug；考核季翻遍 commit 紀錄和 Jira，拼湊這半年的成果。

工作其實都做了，只是沒留下記錄。

Worktrail 的做法是讓紀錄**從開發過程中自然產生**。Claude Code 本來就保存了每段對話，Worktrail 從中讀出時間、單號與 commit，再請 Claude 用你的語氣寫成工作日誌。你只需要做原本就在做的事：寫程式。

---

## 特色

### ⏱ 零操作的自動記錄
每次 Claude 回應結束，Worktrail 就更新這個任務的時數、單號、專案與 commit。不用按開始、不用按結束，也不用切換視窗。

### 🎫 自動認出 Jira 單號與專案
從分支名稱、對話內容、commit 訊息判斷你在處理哪張單；依 Jira 的大型工作（Epic）或工作目錄，自動把任務歸到對的專案。

### ✍️ 由 Claude 撰寫的工作日誌
任務告一段落時，Claude 會把做了什麼整理成子項，並標上完成、待進行、卡住等狀態。上次沒做完的項目會自動帶到下一次，不會漏掉。

### 📊 一鍵產生週報、績效、小交流重點
統計數字由程式精算，文字由 Claude 撰寫，再也不必手動加總時數。支援單週與雙週報；寫法不滿意，到提示詞頁改範本就好，不用改程式。

### 🛟 三層保險，不漏記
hook 每回合擷取 → Claude 寫摘要並有提醒把關 → 每天 18:00 自動掃描補漏。忘了寫的，按一下就補完。

### 📓 好看也好用的介面
今日、日誌熱度圖、報告、提示詞範本，加上淺色、深色與「筆記本」風格。報告可以一鍵複製成圖片貼到聊天軟體，也可以把當天進度複製成 Jira 留言。

### 🔒 資料只留在你的電腦
所有紀錄都是本機資料夾裡的 Markdown 檔，可以用任何編輯器打開。除了呼叫你自己的 Claude，Worktrail 不連網、不上傳，也不碰你的 Jira 帳密。

## 開始使用

1. 雙擊專案資料夾內的 **`一鍵安裝.cmd`**（macOS：`一鍵安裝.command`）。缺少的 Node.js 與 Claude Code 會一併安裝。
2. 開一個**新的** Claude Code 對話，照常開發。
3. 點「啟動 Worktrail」捷徑，看看今天記下了什麼。

不想用了，雙擊 `一鍵解除安裝.cmd` 即可；日誌會保留下來。

### 系統需求

| 項目 | 需求 |
| --- | --- |
| 作業系統 | Windows 10／11（主要支援）、macOS 13 以上 |
| 執行環境 | Node.js 20 以上（一鍵安裝會自動安裝） |
| Claude | Claude Code CLI 或 Claude Desktop 的 Code 分頁，並已登入 |
| Jira（選用） | 已連線的 Jira MCP（例如 `atlassian-rovo-mcp`），用於依父卡片分類與「從 Jira 整理」 |
| 網路 | 只有安裝時需要 |
